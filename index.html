HELP CENTER

Frequently asked questions

Does this website need an account?

No. This beginner version works locally in your browser and does not include login.

Where is my information saved?

Entries are stored in your browser using localStorage. Clearing browser data may remove them.

Can I access my data from another device?

Not in this version. A real multi-user service needs a backend and database.

Can I publish this on GitHub Pages?

Yes. This static HTML, CSS and JavaScript project can be hosted using GitHub Pages.
