# CareerFlow — Simplified Career Tracker

A beginner-friendly static website inspired by the supplied CareerFlow reference page.

## Pages included
- Home / landing page
- Dashboard
- Applications
- Interviews
- Reminders
- Analytics
- Pricing (simple free-plan page)
- FAQ

## Run locally
Open `index.html` in a browser. No installation or build command is needed.

## Data note
This demo stores entries in the current browser using localStorage. It has no real login, cloud database, email reminders, payment system, or multi-device sync. Do not enter sensitive personal information.

## Publish with GitHub Pages
Upload `index.html`, `style.css`, `script.js`, and this README to a GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Your site URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
